1.7 Hypertext Transfer Protocol (HTTP)

Definition

A protocol used for transmitting hypermedia documents, such as HTML pages, over the internet.

HTTP Request-Response

  • Step 1: Client sends HTTP request
  • Step 2: Server processes request and sends HTTP response
  • Step 3: Client renders content based on response
  • Step 4: Client may send additional requests for resources (e.g., images, CSS, JavaScript)
  • Step 5: Server responds to additional requests and client continues rendering until page is fully loaded
  • Step 6: Client may interact with page, sending further HTTP requests (e.g., form submissions, AJAX calls)
  • Step 7: Server processes interactions and sends appropriate responses, allowing for dynamic content updates without full page reloads
  • Step 8: Client and server continue to communicate as needed until user navigates away or closes the browser
  • Step 9: Client may cache certain resources for faster loading on subsequent visits, reducing the number of HTTP requests needed in the future
  • Step 10: Server may also implement security measures (e.g., HTTPS, authentication) to protect data during transmission and ensure secure communication between client and server

Role in HTTP

HTTP is the foundation of data communication on the World Wide Web, enabling the transfer of web pages and resources between clients and servers.

It allows users to access and interact with websites, making it a crucial component of web development and the overall functioning of the internet.

HTTP also supports various methods (e.g., GET, POST, PUT, DELETE) that allow clients to perform different actions on resources, such as retrieving data, submitting forms, updating content, and deleting resources.
