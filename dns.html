1.6 Domain Name System

Definition

A system that translates domain names into IP addresses, enabling users to access websites using easy-to-remember names instead of numerical IP addresses.

Parts of the DNS

  • DNS Servers: Responsible for storing and managing domain name records.
  • Domain Name Registrars: Organizations that manage the reservation of domain names.
  • Zone Files: Contain the mapping between domain names and their corresponding IP addresses.

Role in Web Development

The DNS plays a crucial role in web development by enabling users to access websites using memorable domain names rather than complex IP addresses. It facilitates the resolution of domain names to IP addresses, ensuring that requests for web resources are directed to the correct servers.

DNS in Action

When a user types a URL into their web browser, the DNS is responsible for resolving the domain name to the corresponding IP address of the web server hosting the website. This process involves querying DNS servers to retrieve the necessary information, allowing the browser to establish a connection with the correct server and load the requested web page.

Domain Name parts
  1. Top-Level Domain (TLD): The last part of a domain name, such as .com, .org, or .net.
  2. Second-Level Domain: The part of the domain name that comes before the TLD, often representing the organization or entity (e.g., example in www.example.com).
  3. Subdomain: An optional part of a domain name that can be used to organize and categorize content (e.g., www in www.example.com).
