1.5 Uniform Resource Locators

Definition

A string of characters used to identify a resource on the internet.

Examples

  • https://www.example.com
  • http://localhost:8080
  • ftp://files.example.com

Parts of a URL

  1. Protocol: The method used to access the resource (e.g., http, https, ftp).
  2. Domain Name: The address of the server hosting the resource (e.g., www.example.com).
  3. Port: The specific port number through which to communicate with the server (e.g., :8080).
  4. Path: The location of the resource on the server (e.g., /index.html).
Role in Web Development

URLs are used to locate and access resources on the web, such as web pages, images, and files. They are essential for linking content and enabling navigation between different resources on the internet.
